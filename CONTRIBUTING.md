# Contributing

Thanks for looking. Composer is kept by one person, and I have not read every line of the code (see "How this was built" in the [README](README.md#how-this-was-built)).

- **A bug or a wrong result:** open an issue. There are templates for a bug, an idea and a demo that does not match. Say what you ran, what you saw and what you expected. I read issues with an AI assistant's help, so replies can be slow.
- **Pull requests:** I don't merge them. I can't review code myself, and I'd rather not take changes I can't check. If you have a fix, describe it in an issue; it may be rebuilt and tested here.
- **A security problem:** please don't open a public issue. Use private vulnerability reporting, as described in [SECURITY.md](SECURITY.md).
